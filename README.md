## 🌍 Overview

The Governance Toolkit reimagines how players interact with the political and military systems inside Pax Autocratica. Rather than bolting on disconnected utilities, this project integrates a unified operations layer that speaks the same language as the base game while introducing new dimensions of control, clarity, and consequence.

Think of it as a **cabinet of advisors** who never sleep, never argue, and never leak your tax reforms to the opposition press.

The toolkit is built for three archetypes of ruler:

- **The Architect** — who wants to design a self-sustaining economy before the first winter famine hits.
- **The General** — who sees combat as choreography, not chaos, and prefers battalions to brawls.
- **The Diplomat** — who wins wars by never fighting them, leveraging tariffs, treaties, and carefully timed scandals.

Whichever throne you occupy, the toolkit adapts to your style rather than forcing a doctrine upon you.

## 🏗️ Architecture Overview

The toolkit is organized into layered modules that communicate through a lightweight event bus. This separation ensures that a change to the combat console never destabilizes the colony dashboard.

- **Core Layer** — Configuration, logging, event routing, snapshot persistence.
- **Domain Layer** — Colony, Combat, Diplomacy, and Intelligence modules.
- **Presentation Layer** — Responsive UI, theming, localization, accessibility.
- **Integration Layer** — Adapters that bridge the toolkit with the base game state.

Each layer is independently testable, which means contributors can extend one domain without fear of cascading regressions elsewhere.
